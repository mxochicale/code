# herdr
> Herdr is the runtime your coding agents live on — laptop, desktop, or a box you rent. It holds real terminals open so the work survives the lid closing, and gets you back in from anything with a keyboard.
https://herdr.dev/ 

## installation

```bash
curl -fsSL https://herdr.dev/install.sh | sh
```

## keybinds

Action	Key
Split right	ctrl+b, then v
Split down	ctrl+b, then -
New tab	ctrl+b, then c
Next tab	ctrl+b, then n
Previous tab	ctrl+b, then p
Workspace navigation	ctrl+b, then w
Zoom the focused pane	ctrl+b, then z
Detach	ctrl+b, then q
Show active bindings	ctrl+b, then ?
