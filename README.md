# :school_satchel: Code

## Clone repository
* Generate SSH keys as suggested [here](https://github.com/mxochicale/tools/blob/main/github/SSH.md).
* Setting up signing Git commits with your signing key as suggested [here](https://github.com/mxochicale/tools/blob/main/github/GPG.md).

You can then clone the repository by typing (or copying) the following line in a terminal at your selected path in your machine:
```bash
cd && mkdir -p repositories/mxochicale && cd repositories/mxochicale
git clone git@github.com:mxochicale/code.git
```
